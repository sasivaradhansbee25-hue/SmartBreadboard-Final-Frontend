Positive clipper

shunt · biased

The diode sits across the output with its anode on the output node. When the input rises above \(V_B + V_\gamma\), the diode turns on and holds the output at that level — the top of the wave is cut off. Below that level the diode is off and the output follows the input.

How it works

  1. While \(V_{in} < V_B + V_\gamma\), D1 is reverse-biased (off). No current goes through it, so \(V_{out} = V_{in}\).
  2. When \(V_{in} \ge V_B + V_\gamma\), D1 turns on. The extra voltage drops across R, and the output is held at the clip level.
  3. The negative half cycle passes through unchanged — only the positive peak is clipped.
V_out = V_in (V_in < V_B + Vγ)
V_out = V_B + Vγ (V_in ≥ V_B + Vγ)

Bench notes

  1. Unbiased clipper: set \(V_B = 0\). The output is clipped at about +0.7 V (silicon).
  2. Negative \(V_B\) (cell reversed) moves the clip level below zero, so part of the negative half is clipped too.
  3. Pick R so the diode current stays within its rating: \(I_{max} = (V_m - V_B - V_\gamma)/R\).

Negative clipper

shunt · biased

Same parts as the positive clipper, but the diode is turned around: the cathode is on the output node and the bias cell has its − terminal towards the diode. When the input falls below \(-(V_B + V_\gamma)\), the diode turns on and holds the output there — the bottom of the wave is cut off. Above that level the output follows the input.

Positive clamper

DC restorer

A series capacitor and a shunt diode (cathode on the output) shift the whole waveform up without changing its shape. On the first negative peak the diode conducts and charges C to about \(V_m - V_\gamma\). After that, C acts like a battery in series with the source, so the output swings from about \(-V_\gamma\) up to \(2V_m - V_\gamma\).

How it works

  1. First negative half cycle: D1 is forward-biased and C charges quickly to \(V_m - V_\gamma\), with the + plate on the output side.
  2. Positive half cycle: D1 is off. The capacitor voltage adds to the source, so the output reaches \(2V_m - V_\gamma\).
  3. C can only discharge slowly through \(R_L\). Keep \(R_L C \gg T\) (at least 10T) so the shift stays steady.
V_out(t) ≈ V_in(t) + (V_m − Vγ + V_B)
V_out,min ≈ V_B − Vγ   V_out,max ≈ 2V_m − Vγ + V_B

Bench notes

  1. Notice the first cycle on the scope: the output only settles after the first negative peak. This is the start-up transient.
  2. Try 1 µF with 1 kΩ at 50 Hz. RC is shorter than T, so the capacitor drains and the output sags (tilt).
  3. A biased clamper (\(V_B \ne 0\)) moves the bottom of the wave to \(V_B - V_\gamma\) instead of \(-V_\gamma\).

Negative clamper

DC restorer

Same parts as the positive clamper, but the diode is turned around (anode on the output) and the capacitor's + lead faces the input. On the first positive peak the diode conducts and charges C to about \(V_m - V_\gamma\). After that, C subtracts from the source, so the whole wave shifts down: the output swings from about \(+V_\gamma\) down to \(-(2V_m - V_\gamma)\).
